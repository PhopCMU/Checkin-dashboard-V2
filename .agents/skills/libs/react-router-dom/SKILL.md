Library: react-router-dom (usage in this repo)

When to use:

- Adding routes, nested routes, or navigation helpers.

Steps:

1. Define top-level routes in the app shell and keep pages under `src/pages/`.
2. Use `Link`/`NavLink` for navigation, and `useNavigate` in handlers.

Minimal snippet:

- `import { Link } from 'react-router-dom'`
